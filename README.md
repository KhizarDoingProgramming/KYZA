## 🔥 Features that actually slap

- **Multiple Personalities**: Why settle for one AI when you can have a whole squad? Switch seamlessly between our custom personas (see below). 🎭
- **Immaculate Aesthetics**: We ditched the boring, clinical layouts for something that actually looks good. Think glassmorphism, fluid animations, and a Claude-inspired color palette that’s easy on the eyes. 🎨
- **Text-to-Image Generation**: Just ask Prism and watch the magic happen. Generate high-quality images directly in the chat without breaking a sweat. 🖼️
- **Voice Mode (Live TTS)**: Yeah, she speaks. Real-time voice synthesis because reading long paragraphs is so last year. 🗣️
- **Cloud Sync & Auth**: Powered by Supabase, your chats, settings, and generated images are synced instantly. Switch devices? Your session is right there waiting for you. ☁️
- **Lightning Fast Response Times**: Hooked up to Cerebras and DeepSeek for face-meltingly fast inference speeds. You won't even have time to blink. ⚡

## 🎭 Meet the Squad (AI Personas)

KYZA isn't a monolith. It comes with specialized personas tuned for exactly what you need at the moment:

1. **Nova 🧠**: Your go-to brainiac. Best for complex logic, deep reasoning, and step-by-step problem solving.
2. **Atlas 🌍**: The generalist. Perfect for writing, brainstorming, and everyday questions. Balances speed with massive knowledge.
3. **Helix 🧬**: The coder's best friend. Need a React component or a Python script? Helix drops flawless code blocks every single time.
4. **Prism 🎨**: The creative soul. Ask Prism to "draw" or "generate an image" and it hooks into Pollinations AI to drop custom artwork straight into the chat.

## 🛠️ Tech Stack & Architecture

We didn't skimp on the engineering. Here's what's powering this beast under the hood:

### Frontend
- **React + TypeScript**: For a rock-solid, type-safe UI.
- **Vite**: Because waiting for Webpack to compile is torture.
- **TailwindCSS**: For rapid, beautiful styling without leaving the component.
- **Three.js / React Three Fiber**: (For those sick 3D avatar animations like Nina).

### Backend & Cloud
- **Node.js**: Handling the proxy routes and keeping our API keys safe from the client.
- **Supabase**: Open-source Firebase alternative handling Postgres DB, Auth, and Storage.
- **Vercel**: Flawless, edge-network deployments.

### AI Engine Room
- **Cerebras**: Supplying mind-bending inference speeds.
- **DeepSeek**: Top-tier open-source reasoning models.
- **OpenRouter**: The ultimate AI routing layer.
- **Pollinations AI**: Free, fast, text-to-image magic.

## 🚀 Getting Started Locally

Want to run this beast locally and tinker with the code? Say less. Follow these steps to get KYZA running on your machine.

```bash
# 1. Clone the repo to your local machine
git clone https://github.com/KhizaDoingProgramming/KYZA.git

# 2. Move into the project directory
cd KYZA

# 3. Install dependencies (npm, yarn, pnpm - pick your poison)
npm install

# 4. Setup environment variables securely
cp .env.example .env
# Open the .env file in your code editor and add the api keys. 
# (Don't worry, .env is gitignored so your keys won't leak!)

# 5. Fire up the dev server
npm run dev
```

Boom. You're live on `localhost:3000`. Navigate there in your browser and start chatting.
